# Tank Battle Arena Backend API - Quick Guide

This backend uses FastAPI + SQLAlchemy with a SQLite database (default: `./data/app.db`, or override via `DATABASE_URL`).

Key components:
- src/api/db.py: SQLAlchemy engine/session and dependencies
- src/api/models.py: ORM models (User, Tank, Match, PlayerState, LeaderboardEntry)
- src/api/schemas.py: Pydantic schemas for API IO
- src/api/main.py: App setup, auto table creation, and router wiring
- src/api/seed.py: Minimal seeding utility (two users, tanks, a match, player states, leaderboard)
- src/api/*_routes.py: Modular routers for diagnostics and simple CRUD/read endpoints

Verification steps:
1) Health check: GET /
2) DB info: GET /system/db-info
3) Tables list: GET /system/tables
4) OpenAPI meta: GET /system/openapi-meta
5) Seed data: POST /system/seed-minimal
6) Confirm leaderboard: GET /leaderboard
7) Users CRUD:
   - POST /users {"username":"testuser"}
   - GET /users
8) Tanks CRUD:
   - POST /tanks {"user_id":1,"color":"blue","speed":1.1,"armor":1.0,"damage":1.0}
   - GET /tanks
9) Matches:
   - POST /matches {"status":"ongoing"}
   - GET /matches
10) Player states:
   - POST /player-states {"match_id":1,"user_id":1,"x":0,"y":0,"angle":0,"health":100,"score":0}
   - GET /player-states

Notes:
- Tables are created automatically at application startup.
- All routes use the get_session dependency to manage transactions.
- Use interfaces/openapi.json (generated by running src/api/generate_openapi.py) to view API schema.
